# 任务：Hugging Face 周热榜 Top 5 视频（hugging-face-top-5）

> 每周六北京时间 17:00 左右启动。
> 在装有现有管线的机器上执行，工作根目录 `E:\Repository\video-code`。一次任务产出**一期**去重后的 Top 5 视频，约 5–6 分钟。

## 0. 总原则

- 榜单口径不偷换；事实与观点分开；素材可追溯；交付按实际完成情况说明，不把失败藏起来。
- 榜单单位是**合并后的模型**，不是重复发布的仓库；先合并变体，再选 Top 5。
- 新建当周目录，复用上一周结构，**不覆盖历史产物**。

## 1. 周次与目录

- 周次 = 启动日所在 ISO 周历周（周一为一周之始）。目录：`video-code/hf-trending-<year>w<week>/`（扁平结构，不分 ai/other）。
- 参考实例：`video-code/hf-trending-2026w47/`。

## 2. 榜单获取与去重

1. 通过 HF API（`https://huggingface.co/api/models?sort=trendingScore&limit=10&full=true`）或已登录 `hf` CLI 获取 trending models；保留原始排序与仓库身份：
   - 原始 JSON → `raw/trending_models.json`；抓取时刻 → `raw/snapshot_time.txt`（北京时间，附 PST 对照）。
2. **去重**：若有模型在最近两周的视频中已经详细介绍过，本周一笔带过即可，详细介绍的名额向后顺延。
3. 记录前五之后的下一名，以及上周前五本周的去向（名次、点赞、下载变化），供脚本与 README 使用。

## 3. 研究证据（分层，而非只有参数表）

| 层 | 要求 |
|---|---|
| 官方层 | 阅读 model card、技术文档和论文；解释关键设计、训练方式与结果，聚焦该模型的独特之处。作者自报评测明确写"官方自报"。 |
| 外部层 | 查社区讨论及 LMArena、Artificial Analysis 等独立评测；说明来源与适用版本；未收录或无法获取时说明，不补造。 |
| 真实样例 | ZeroGPU 额度充裕时尝试官方 Space；若模型能单卡部署，也可在 colab 的 GPU 上实测；若没有官方 Space ，或硬件配置不足以实测，则不应包装成完整实测。 |
| 表达层 | 社区意见以归纳方式呈现，不伪装直接引语；数据不一致处只记录事实，不自行推断。 |

可选复核（非每周每项必做）：拉取公开点赞列表 `/api/models/<repo>/likers` 做账号注册时间分布分析，只对榜单可信度进行简单评估，不做其余推断。

## 4. 脚本（少科普，多讲设计）

- 片头一句日期开场，自然衔接模型，结尾回顾；约 5–6 分钟。
- 讲架构设计、训练取舍、具体用例与评测对照；不科普 transformer、MoE、LoRA、diffusion 等基础概念；不逐个念参数表。
- 统计放图表；启示融入分析，不设僵硬"启示"段落。
- 画面风格可参考往期视频。

## 5. 制作管线

文件链（扁平放在当周目录）：

```
build_data.py → data.json → script.py（旁白）→ tts.py（配音，产出 timing.json + audio/）
→ prep_assets.py → scenes.py + render.sh（Manim，逐场景按顺序渲染）
→ sheet.py（每场景抽帧检查，结果在 build_chk/）
→ assemble.py（ffmpeg 拼接、烧录字幕、生成 SRT、响度归一）
→ checkcut.py（成片抽帧，结果在 build_chk_final/）
封面：make_covers.py .（读取 cover.json 和 data.json）
```

- **画面**：Manim 1080p30（1920×1080），沿用 HF 系列风格；图表用 Manim 按模型卡、博客、评测页与自抓数据重绘，画面注明出处。
- **配音**：MiniMax 中国站 `speech-2.8-hd`，音色 `male-qn-jingying`（精英青年），speed 1.1，可通过已登录的 mmx-cli 进行调用；按场景合成，每段前约 0.25s、后约 0.65s；用词级时间戳（`subtitle_type=word`）生成 timing.json 与字幕；保证语音的间隔与语义的间隔对齐，避免出现同一短语内的词汇间隔长而不同语句的间隔短；多音字与英文名用 `pronunciation_dict` 校正；整片约 -16 LUFS。
- **字幕**：烧录约 60px 中文 ASS；同时生成独立 SRT；只在句读标点处断行。
- **合成**：ffmpeg、x264 crf20、faststart；响度 loudnorm -16 LUFS。
- **逐场景视觉检查**：`sheet.py` 抽帧查重叠、裁切、拥挤，修复后重渲染再合成；`checkcut.py` 复核成片。
- **封面**：三尺寸 1920×1080、1440×1080、1080×1440；系列风格 + 日期 + 头像 + 排名 + 类型 + 短中文说明 + 关键指标，第一名突出；全尺寸与缩略图查可读性。
- **素材与许可**：头像取各组织/作者 HF 头像；字体 Noto Sans CJK（SIL OFL）；来源与许可记入 README 素材表，含"下载了但未使用"的素材。含成人向等敏感内容的模型只做结构与热度说明，不展示样例。
- **环境**：conda 环境`video`，位于`E:\Runtime\anaconda\envs\video`，包含manim、Pillow等；若有缺失依赖则在该环境中进行修复。

## 6. README.md（当周工程说明，随产物留存）

按近期格式记录：成片与封面清单、榜单快照与时间、去重后榜单表（名次/模型/类型/点赞/30 天下载/热度分）、合并规则与未合并判定、自报/第三方/社区观点分层、实测情况（本周是否调用 Space、是否有上机实测）、素材来源与许可、安全声明、旁白与时间戳处理、流水线与环境。历史分析是实例，不是下周的固定要求。

## 7. 交付（在本聊天中交付）

完整包：`hf_trending_top5_w<ww>.mp4` + 对应 `.srt` + 三张封面 + `description.txt`。

交付顺序：① 先附 MP4；② 简短中文名单，每条带可点击链接，标明类型与特色；③ 说明必要局限并附三张封面；④ 最后单独代码块贴简介；SRT 保留可交付。

`description.txt` 模板：

```
Hugging Face 周热榜 Top 5（<年份> 年第 <周次> 周 · <日期>）｜<一句 hook>

#5 <org/name>：<一句总结（类型 + 特色）>
<完整 URL>
（按实际数量续写 #4…#1，不足五项不伪造）

数据来源：Hugging Face Trending Models（<API 地址>），名次为除前两周上榜模型外的前五。
```

最后提交 git，commit message 遵循标准规范；只提交文本文件、代码，避免提交二进制文件。

## 8. 验收（未完成不得写成已完成）

- [ ] 榜单：榜单已获取，详细介绍的与一笔带过的分清；原始名次与映射保留。
- [ ] 研究：官方/外部/样例分层清楚；自报与独立评测有区分；不确定性已标注；无伪造结论。
- [ ] 内容：日期开场、自然过渡、结尾回顾；无基础概念科普、无参数表朗读。
- [ ] 制作：逐场景顺序渲染；每场景抽帧检查并修复重渲染；成片抽帧复核。
- [ ] 规格：1080p30；60px 标点断行字幕 + 独立 SRT；配音参数符合要求；约 -16 LUFS。
- [ ] 封面：三尺寸齐备、第一名突出、各尺寸可读。
- [ ] 交付：MP4 + 三封面 + 简介齐备；缺项与数据不一致如实说明。
- [ ] （建议）完整播放成片复核：音画同步、字幕先后、黑帧、片尾截断、多音字与英文模型名读音。

保留一行验收结论，例：`榜单/来源已核对；场景抽帧已完成；全片复核[已完成/未完成]；备用配音[是/否]；已知局限[说明]`。

## 9. 失败分支

| 情形 | 处理 |
|---|---|
| 榜单不可用 | 如实报告，不换榜。 |
| Space 或独立评测不可用 | 记录限制；无结果不宣称实测成功，无外部评测不冒充独立验证。 |
| MiniMax 异常 | 认证、额度或服务异常时换 `edge-tts zh-CN-XiaoxiaoNeural` 兜底，**交付时披露切换及影响**；仍失败则报告已完成环节与缺失产物。 |
| 环境 / 渲染失败 | 用 conda-forge 恢复；画面问题修复后重渲染。 |

## 10. 安全与保密

- 只读调研：不执行模型仓库代码、不加载 pickle 权重、不下载大权重；只用模型卡、论文、官方演示素材与允许访问的在线样例。
- 文档与对外交付不包含密钥、token、账户详情或密钥文件路径。
